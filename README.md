# Weather Dashboard web application (Project)

A premium and responsive Weather Dashboard web application developed using HTML, CSS and JavaScript. This project provides real-time weather updates with dynamic weather themes, animated UI and glassmorphism effects.

---

# Features

- Real-time weather information
- Dynamic weather-based backgrounds
- Search weather by city name
- Premium glassmorphism UI
- Fully responsive design
- Animated weather icons
- Dark aesthetic interface
- Air quality section
- Humidity, pressure and wind details
- Theme changing button
- Smooth animations and transitions

---

#Technologies Used

- HTML5
- CSS3
- JavaScript
- Weather API

---

# Functionalities

- Displays:
  - Temperature
  - Weather condition
  - Humidity
  - Wind speed
  - Pressure
  - Rain percentage
  - Feels like temperature
  - Air quality

- Dynamic themes for:
  - Sunny weather
  - Rainy weather
  - Cloudy weather
  - Snow weather
  - Thunderstorm weather

---

#How to Run

1. Download the project
2. Open the project folder
3. Run `index.html`
4. Search any city name
